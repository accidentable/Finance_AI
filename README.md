# 분쟁72 · 사건을 연결하는 해외결제 대응 보드

첫 화면은 입력창 하나에 집중합니다. 입력 이후에는 거래·메일·확인할 질문·공식 안내·다음 행동을 연결한 사건 보드를 제공합니다.

## 실행

```sh
npm ci
npm run dev
```

http://localhost:3000 에서 시작합니다. 입력창 아래 **예시로 살펴보기**의 합성 사건 3종은 API 키 없이 작동합니다. 이는 미리 작성한 데모이며 실제 AI 분석으로 표시하지 않습니다.

실제 분석은 `.env.example`을 `.env.local`로 복사한 뒤 서버 환경변수 `OPENAI_API_KEY`를 설정하세요. `OPENAI_MODEL` 기본값은 기존 프로젝트의 `gpt-5.6-sol`을 유지합니다. 계정에서 사용 가능한 Structured Outputs 지원 모델로 변경할 수 있습니다. 키를 화면이나 Git에 입력하지 마세요.

## 구현한 흐름

- 텍스트 입력 / .txt 첨부 → 전송 전 마스킹 확인 → OpenAI Responses API 분석
- 구조화된 사실 추출 → 원문 인용 대조 → 공식 안내와 연결 → 질문·행동·초안 생성
- 드래그·확대·화면 맞춤 사건 보드, 단서 상세 패널, 시간순 보기
- 새 회신 추가 후 재분석. 갱신 전후 단서 개수와 거래 상태 변화 표시
- 영문 문의, 국문 상담용 사실 정리, 타임라인 복사 및 Markdown 내보내기
- 사용자가 저장 버튼을 누르면 이 브라우저에 사건 하나 저장. 7일 만료 시 다음 앱 실행/불러오기에서 삭제. 서버 저장·공유 링크는 구현하지 않음
- 모바일에서는 확대된 보드 대신 읽기 쉬운 카드 흐름으로 표시

## OpenAI 연결

서버에서만 SDK를 호출합니다. `responses.parse` + Zod Structured Outputs, `store: false`, 입력 길이·스트림 크기 제한, 취소 시 요청 중단을 적용했습니다. 공개 API 스키마 참고: https://developers.openai.com/api/docs/guides/structured-outputs

실제 모델 호출에는 API 키와 모델 접근 권한이 필요합니다. 키가 없으면 오류를 명확히 표시하고 입력을 유지합니다. 자동 데모 응답으로 대체하지 않습니다.

## 판단 범위와 데이터

- 승인·매입·거절·청구서 상태를 구분하며 상태가 섞이면 확인이 필요합니다.
- 검증된 카드사별 기한 규칙이 없으므로 D-day와 사유코드를 확정하지 않습니다.
- 승인 거절이어도 추가 결제 방지를 위한 카드사 상담을 제외하지 않습니다.
- 도메인 목록 일치를 메일 인증으로 표현하지 않습니다.
- `lib/rules.ts`는 일반 참고 자료입니다. 개별 사건의 환불 권리나 필수 서류를 보장하지 않습니다.
- 첨부 이미지 분석은 이번 버전에서 제외했습니다. 이미지 내부 개인정보를 제대로 확인·제거하는 흐름이 먼저 필요합니다.
- 개인정보 패턴 탐지는 완전한 익명화가 아닙니다. 사용자가 전송 텍스트를 확인·수정합니다.
- 서버 DB에 원문을 저장하지 않습니다. OpenAI의 `store: false`가 모든 제공자 로그의 미보관을 보장한다는 뜻은 아닙니다.
- 공개 배포 전에 인증, 분산 요청 제한, 개인정보 정책, 실무 규정 검수 및 실제 사례 평가가 필요합니다.

## 검증

```sh
npm test
npm run typecheck
npm run build
```

테스트는 개인정보 마스킹, 원문에 없는 증거 제거, 기한 보류, 발신 도메인 오인 방지, 합성 사례 스키마/연결 근거, API 입력 검증 및 SDK 모의 응답 연결을 확인합니다. 모의 응답 검증은 실제 모델 품질 평가를 대신하지 않습니다.

## 구성

- `app/page.tsx`: 첫 화면, 보드, 단서 상세, 갱신·초안·브라우저 저장
- `app/globals.css`: 중립색 배경, 녹색 연결선, 반응형 카드 레이아웃
- `app/api/agent/route.ts`: 입력 제한 및 SSE 응답
- `lib/agent.ts`: 서버 OpenAI 분석 파이프라인
- `lib/case.ts`: 응답 스키마와 검증 함수
- `lib/rules.ts`: 출처가 있는 일반 안내
- `lib/samples.ts`: 합성 데모 3종

기존 `01_기술명세서.md`는 초기 버전 기록입니다. 현재 동작은 이 README와 구현을 기준으로 합니다.

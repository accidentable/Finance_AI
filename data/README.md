# 규정·절차 데이터

구독컷이 LLM 없이 참조하는 근거 자료입니다. 모든 항목에 출처 URL과 조회일(`accessed`)이 붙어 있고, `verified` 등급으로 확인 수준을 표시합니다. 로더는 `lib/knowledge.ts`, 형식 검증은 `tests/knowledge.test.ts`입니다.

| 파일 | 내용 | 건수 | 확인 수준 |
|---|---|---|---|
| `issuers.json` | 카드사 9곳 해외이용 이의신청 절차 (채널, 기한, 사유, 서류, 처리기간) | 9 | official 3 (KB, 우리, BC) · partial 4 (신한, 롯데, 하나, NH) · secondary 1 (삼성) · community 1 (현대) |
| `reason-codes.json` | Visa·Mastercard 분쟁 사유코드, 카드홀더 기한, 사건 유형 매핑, 한국어 주의사항 | 14 | secondary (분쟁관리 업체 정리본). 원문은 Visa Core Rules / Mastercard Chargeback Guide |
| `merchant-policies.json` | AI·클라우드·SaaS 사업자 18곳의 환불·해지·미승인 청구 정책과 공식 창구 | 18 | official 9 · secondary 8 · partial 1 |
| `authorities.json` | 금감원 2026-06 안내, 소비자원 차지백 가이드(120일·45일), 국제거래 소비자포털, 표준약관 14일 이의 | 7 | official·news |
| `notification-patterns.json` | 카드 승인 문자 파싱 패턴(승인 유형, 통화·금액, 일시, 가맹점 표기) | 1 | pattern-only |

## 확인 수준의 의미

- **official**: 공식 페이지 본문을 직접 읽어 정리했습니다.
- **partial**: 공식 페이지 일부만 읽었거나, 검색 색인 요약에 의존했습니다. 화면에서는 "카드사 확인 필요"를 함께 표시합니다.
- **secondary**: 공식 페이지 접근이 막혀(403) 검색 요약이나 2차 정리본으로 확인했습니다.
- **community**: 이용자 경험담에 의존했습니다. 절차 힌트로만 쓰고 확정 문구로 쓰지 않습니다.
- **pattern-only**: 실제 샘플로 검증하지 않은 정규식입니다.

## 수집에서 확인된 핵심 사실

- 카드사 안내 기한은 "승인일·전표 접수일로부터 45~120일" 범위에 모입니다. KB국민카드는 110일, BC카드는 75~120일, 금감원은 90~120일로 안내합니다. 국제브랜드 규정의 통상 120일과 일치하며, 사유코드별 기준일이 달라서 서비스는 이를 "참고 기한"으로만 표시합니다.
- 처리 기간은 KB 2~4개월, 삼성 45일~3개월, BC 3개월 이상, 우리 45일~120일(최장 6개월), 금감원 3~5개월입니다.
- 소비자원 차지백 가이드: 신청 기간은 거래일 또는 물품배송일로부터 120일, 가맹점은 카드사에 45일 안에 답변.
- 우리카드는 결제일 1영업일 전까지 신청하면 종결까지 청구보류. 현대카드도 청구보류 병행을 권하는 이용자 보고가 있습니다.
- 사업자 환불 정책은 "원칙 불가 + 지역별 청약철회 예외"가 대부분입니다. OpenAI와 Perplexity는 한국 거주자의 7일 청약철회를 명시합니다. Cursor는 14일 이내·미사용 시, Notion은 월간 3일·연간 30일, Midjourney는 GPU 20분 미만일 때만 환불합니다.
- 결제대행 표기(STRIPE *, PADDLE.NET*)는 판매자를 먼저 찾아야 합니다. Stripe는 charge lookup 도구를 제공하고 대신 환불하지 않습니다.
- API 키·계정 도용은 카드 도용 사유코드(Visa 10.4, MC 4837)에 해당하지 않는 경우가 많습니다. 사업자의 미승인 사용 검토가 1차 경로입니다.

## 미확인·보완 필요

- 신한카드·현대카드 공식 이의신청 페이지는 동적 렌더링 또는 미발견으로 본문을 읽지 못했습니다. 앱 메뉴 경로와 서류 목록을 직접 확인해 채워야 합니다.
- 하나카드·NH농협카드·롯데카드는 해외 분쟁 전용 절차 페이지를 찾지 못했고 표준약관과 고객센터 번호로 대체했습니다.
- OpenAI·Midjourney·Perplexity·Canva·Adobe 도움말은 자동 접근이 차단돼 검색 요약으로 확인했습니다. 발표 전 브라우저에서 한 번씩 열어 문구를 대조해야 합니다.
- 카드사별 실제 알림 문자 샘플이 없어 `issuerFormats`가 비어 있습니다. 샘플을 확보하면 카드사별 정확한 파서를 추가합니다.
- Visa·Mastercard 규정 원문(PDF)은 분량이 커서 2차 정리본을 썼습니다. 코드별 기한은 원문으로 재확인이 필요합니다.

## 수집 방법

2026-09-06에 웹 검색과 공식 페이지 본문 추출로 수집했습니다. 검색 결과는 색인 요약이므로 가능한 한 본문을 다시 읽어 확인했고, 읽지 못한 항목은 `verified`를 낮춰 표시했습니다.
